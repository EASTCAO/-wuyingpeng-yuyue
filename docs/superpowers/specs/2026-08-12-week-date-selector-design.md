# 每周日期选择器设计

## 目标

将大厅顶部的“今天 / 明天”切换改为每次显示一周 7 天的日期选择器，方便摄影师直接查看并选择具体日期。

## 交互

- 日期条按周一到周日排列，每个日期显示星期和月日。
- 默认展示今天所在周并选中今天。
- 左右箭头分别切换上一周和下一周，每次移动 7 天。
- 点击任意日期后，只展示该日期的影棚预约状态和预约记录。
- 当前选中日期使用蓝色背景突出显示；今天在未选中时保留轻量标识。
- “大厅”入口保留在日期条右侧，不改变现有视图切换逻辑。

## 数据与兼容性

- 继续使用现有 `selectedDate` 和 `currentDateRange = 'custom'`，不改变预约数据结构。
- 管理员可以通过上一周箭头查看历史日期；普通用户的既有历史预约过滤规则保持不变。
- 桌面端完整展示 7 天；窄屏允许日期区域横向查看，按钮尺寸保持可点击。

## 验证

- 默认周包含连续 7 天，并以周一为第一天。
- 切换上一周或下一周后日期整体移动 7 天。
- 点击日期后 `getDisplayDates()` 只返回选中日期。
- 6F、7F、无影棚和实景棚均随选中日期刷新。
